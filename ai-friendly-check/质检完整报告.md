## 三、高频系统性缺陷（优先修复）

这几类是波及面最广、对 AI Agent 危害最大的系统性问题：

1. **字段名拼写错误跨库大面积复现**
   - `bardcode`（应 `barcode`）——出现在 **14 篇** reference（createpayment/showpayment/capturepayment/paysession 等），字段名与其描述 "Barcode number" 自相矛盾。
   - `transacion_key`（应 `transaction_key`，iDEAL 支付明细）——同样 **14 篇**，且与同篇其他支付方式的 `transaction_key` 不一致。
   - Agent 按正确拼写解析响应会全部取空。

2. **接口 200 响应描述整段复制串题**
   - showfile、showliveapplication 的 200 描述都写成 "Creates a new file for its submerchant"；paysession 的 200 写成 "Cancels the session."。Agent 据此会完全误判接口行为。

3. **示例 JSON 语法非法**
   - platform-processing-model.md / seller-processing-model.md 共 6 处 curl 请求体键写成 `"amount'`（双引号开、单引号闭）+ 尾随逗号，任何 JSON 解析器都报错。

4. **同一状态/枚举跨文档口径打架**
   - PaymentStatus（散文表 6 态缺 `failed` vs schema 7 态）、Subscription.status（5 态生命周期 vs 举例含非法 `cancelled`）、Session 成功态（`completed` vs `complete`）、tax 缺省计税（新版 tax=0 vs 旧版 auto=10%）。
