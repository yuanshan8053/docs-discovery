# docs-discovery

KOMOJU 全套英文文档 AI 友好度 & 专业性质检成果。

## 目录

`ai-friendly-check/`：

- `问题清单.md` — AI 友好度质检问题清单（通俗版），含 `.md` 原文位置（行号 + 出错片段摘录）与渲染页链接，共 31 条**点状缺陷**（高 22 · 中高 7 · 中 2）。质检维度：字段名拼写、说明与实现一致性、枚举缺失、跨文档口径冲突、代码示例可运行性、术语/命名一致性等。
- `API文档使用阻碍评审报告.md` — 站在 API 使用者立场的**结构性使用阻碍**评审报告，共 18 类阻碍（高 9 · 中高 6 · 中 3），附按 P0→P2 排序的改进建议清单。聚焦字段普遍无说明、枚举无含义、示例缺失、错误码/限流不写等成规模缺口。
- `API文档专业性提升清单.md` — 上述评审的通俗精简版，9 条提升项（高 4 · 中高 4 · 中 1），改进建议并入表格，与《问题清单》无重复。
